# 12. Боссы

**Суть.** Пять боссов, по одному в конце каждой глубины. Каждый проверяет то, чему научила его глубина (Kishōtenketsu: «кэцу»).

## Намерение

Бой с боссом — экзамен на чтение: все приёмы честно показывают замах, после каждого есть окно для ударов. Вторая фаза злее, но не нечестнее.

## Правила

1. Вход: пауза 1.6 с, надпись с именем и титулом, рёв, тряска. Полоса HP внизу экрана с «запаздывающим» белым следом.
2. **Мозг:** босс подходит к герою 0.4–1.0 с, затем выбирает приём по весу (тот же приём два раза подряд не выбирается, если есть другие).
3. **Вторая фаза** при HP < 50%: надпись «ярость», к приёмам добавляются приёмы второй фазы, скорость ×1.2, замахи ×0.85 (но не ниже 0.40 с). Уже начатый замах не ускоряется.
4. **Контр по боссу:** удар в окно в конце его замаха = ×1.3 и ошеломление (без потери окна).
5. Ошеломление босса — короткая пауза, а не полное прерывание серии; заморозка 0.5 с.
6. **HP** = база × `(1.15 + 0.15 × глубина)`: I ×1.3, II ×1.45, III ×1.6, IV ×1.75, V ×1.9.
7. **Удары:** рывок оглушает героя на 0.45 с, дуговые серии замедляют на 1.2 с. Приёмы с базовым уроном ≥ 24 снимают 2 сердца.
8. **Награда:** весь пепел забега сохраняется в Древо, нектар восполняется, +2 сердца, вещь не ниже Героической (на V ещё одна не ниже Титанической), ресурсы (модуль 09), затем «Дар за подвиг». Победа над V боссом завершает игру («Сад Гесперид спасён»).

## Приёмы (общие кирпичики)

| Приём | Что делает |
|---|---|
| slam | удар о землю: круг радиусом `r` вокруг босса |
| charge | рывок по прямой со скоростью `speed` на `dur` с (иногда оставляет огненный след) |
| spikes | ряд шипов из-под земли к герою (`count` шт., шаг `step`), веером `fan` |
| ring | кольца из `n` пуль, `waves` волн через `gap` |
| volley | веер из `n` пуль, разлёт `spread`, `bursts` очередей |
| blink | исчезает и появляется рядом с героем, удар по кругу |
| combo | серия ударов-дуг |
| rain | `count` падающих кругов вокруг героя |
| spiral | спираль пуль `arms` рукавов на `dur` с |
| summon | призывает врагов |

## Код

`src/data/bosses.js` (числа и приёмы), `src/game/boss.js` (мозг, приёмы, фазы, рисунок).

## Ручки

- Веса приёмов: чем чаще приём, тем раньше игрок его выучит.
- Множитель HP `1.15 + 0.15 × глубина`.
- Порог второй фазы 50%.

## Проверка

- `npm run balance`: замахи второй фазы ≥ 0.40 с, окна ≥ 0.55 с; бой с ожидаемым героем длится 35–130 с.
- Бот с бессмертием убивает всех пятерых без ошибок.

## Открыто

- У боссов нет уникальных механик арены (только приёмы).
