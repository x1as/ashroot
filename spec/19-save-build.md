# 19. Сохранения, промокоды, сборка

**Суть.** Одиночная игра в браузере: прогресс хранится в браузере игрока, переживает обновления игры, а для тестов есть промокоды и полный сброс.

## Сохранение

1. Хранится в `localStorage` под ключом основной копии и резервной (каждая запись пишется в обе). Испорченная основная копия заменяется резервной. Если хранилище недоступно (приватный режим), игра работает без сохранения.
2. Схема версии 3: пепел, купленные узлы Древа, тень, звук, инвентарь (вещи, ресурсы, надетое, летопись), статистика (забеги, победы, лучшая глубина, убийства, смерти, идеальные перекаты, контры, боссы, лучшее время, заработанный пепел), достижения, служебные поля читов.
3. **Миграции:** каждая старая версия поднимается до текущей по шагам. Переход 2→3 (удаление классов) вернул весь вложенный пепел и выдал стартовый набор.
4. При загрузке пепел, тень и ресурсы округляются до целых.
5. Сохраняется: при выходе из зала, при смерти, при победе над боссом, при закрытии сокровищницы, при покупке узла, при применении кода.
6. **Пепел:** в забеге копится «несохранённый». Босс переносит весь пепел в Древо. Смерть: 50% (75% с «Памятью Мнемосины») в Древо, остальное — тень (модуль 13).
7. Есть экспорт и импорт сохранения строкой (функции в коде, без интерфейса).

## Промокоды (Настройки → поле «Промокод»)

1. Поле без подсказок и примеров: ни плейсхолдера, ни списка кодов в интерфейсе.
2. Коды хранятся только хэшами (cyrb53 от кода в верхнем регистре, латиница и кириллица), поэтому их нельзя прочитать ни в репозитории, ни в собранном файле. Сам список кодов есть только у владельца, в публичных файлах его нет.
3. Наборы наград: «всё сразу» (Древо полностью, +50 000 пепла, +999 каждого ресурса, все предметы), «пепел» (+10 000), «Древо» (все узлы на максимум), «ресурсы» (+999 каждого), «арсенал» (каждая база Божественной +10, каждое оружие ещё Титаническим +5, все 6 реликвий, сумка расширяется), «бессмертие» (вкл/выкл, сохраняется).
4. Неверный код: «Промокод не подошёл.»
5. Новый код: посчитать хэш `cyrb53(КОД)` и добавить в `HASHES` в `settings.js`.

**Сброс:** «Сбросить весь прогресс» → «Точно? Всё удалится. Нажми ещё раз» (4 с) → удаление обеих копий и перезагрузка.

**Отладка** (`?debug` в адресе): N — убить всех, B — к боссу, G — +500 пепла, H — полные сердца и щиты, I — бессмертие, O — открыть выходы. `window.__G`, `window.__dbg`, бот `tools/bot.js`.

## Сборка и выкладка

| Команда | Что делает |
|---|---|
| `npm run dev` | сервер на http://localhost:5173 |
| `npm run build` | esbuild собирает один файл: `index.html`, `dist/index.html`, `dist/ashroot.html` (~350 КБ, шрифты подключаются из Google Fonts) |
| `npm run balance` | симулятор баланса (модуль 14) |
| `npm run deploy` | сборка и выкладка `dist/` в ветку `gh-pages` |

| `npm run shots` | headless Chrome через протокол DevTools выставляет сцены в настоящей игре и снимает `docs/shots/*` (бой, босс, сокровищница, Древо) и обложку `docs/og.png` 1200×630 (`npm run shots -- cover` — только обложку) |
| `npm run icons` | иконка сайта: пиксельный коринфский шлем с плюмажем 16×16 → `public/favicon.png`, `icon-192.png`, `apple-touch-icon.png` |

Страница на GitHub Pages несёт иконку, описание и превью ссылки (Open Graph и Twitter: заголовок «Ashroot — Тринадцатый подвиг Геракла», обложка `og.png`). Сборка копирует `public/*` и `docs/og.png` в `dist/`.

Репозиторий: github.com/x1as/ashroot, игра: x1as.github.io/ashroot. Каждое изменение: сборка → баланс → бот → коммит в `main` → пуш → выкладка → проверка живой страницы.
