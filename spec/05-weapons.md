# 05. Оружие

**Суть.** Десять типов оружия. Тип решает всё: форму и ритм ударов, скорость хода во время атаки, усиленную атаку и против кого ты силён.

## Намерение

Взяв новое оружие, игрок должен играть иначе, а не «то же, но с другим уроном». Каждое оружие — архетип из экшен-игр, названный по-гречески: меч-баланс, парные клинки, тяжёлая палица, посох, лук, копьё, щит и меч, двойной топор, секира палача, огромный тесак (в духе меча Гатса).

## Правила

1. Каждое оружие ДОЛЖНО иметь: свой спрайт в мире и иконку, свой рисунок и форму каждого удара комбо (модуль 04), свою усиленную атаку (модуль 06), строку «силён против / слаб против».
2. Комбо проходит удары по порядку, последний удар — финишер (сброс комбо).
3. **Ход** — множитель скорости бега во время удара. Тяжёлое оружие медленнее.
4. **Отмщение** — сколько урона нужно, чтобы вернуть призрачное сердце (модуль 03). Меньше число = нужно больше урона. Быстрое оружие получает больше, потому что бьёт мелко.
5. Махайры рисуются по клинку в каждой руке, удары чередуют руки, финишер работает обеими. Аспис рисует круглый щит на второй руке: щит поднят вперёд, когда герой не бьёт и не перекатывается.
6. Металл оружия меняется с редкостью: железо, бронза, сталь, золото. Титаническое и Божественное светятся (модуль 17).
7. Оружие из Древа (колонка «Открытие») не выпадает, пока его узел не куплен. При покупке узла игрок сразу получает Героический экземпляр (модуль 10).
8. Урон в таблицах — базовый: потом умножается на мощь предмета, Древо и дары.

## Связи

Формы и путь урона — 04. Усиленные атаки — 06. Дары под конкретное оружие — 07. Божественные версии оружия — 08. Открытие — 10. Проверка «камень-ножницы-бумага» — 14.

## Код

`src/data/weapons.js` (все числа), `src/game/player.js` (удары, рисунок оружия в руке), `src/art/pixels.js` (спрайты в мире), `src/art/items.js` (иконки 16×16), `src/data/items.js` (базы предметов `w_*`).

## Ручки

- Урон, тайминги, дальность — свободно, затем `npm run balance`.
- Форма удара (`shape`): `arc`, `line`, `cone`, `impact`, `cross`, `spin`. Для `line` и `cross` нужна `width`, для `impact` нужен `r`, а `range` у него означает расстояние до центра.
- Новое оружие: запись в `WEAPONS` + база `w_*` в предметах + спрайт + иконка + приём в модуле 06 + узел Древа.

## Проверка

- У каждого из 10 оружий три удара комбо выглядят по-разному и задевают по своей форме.
- `npm run balance`: у каждого оружия есть хотя бы один сильный и один слабый враг.
- Бот проходит забег каждым оружием без ошибок в консоли.

## Открыто

- Посох и лук бьют снарядами, у них нет формы удара ближнего боя.
- Иконки дори и тесака в сумке похожи на лук и меч на маленьком размере.
