# Ashroot: правила для Claude

- Источник правды — модули в `spec/` (индекс: `spec/00-INDEX.md`). Перед любой правкой прочитай модуль системы, которую трогаешь.
- «Пересобери модуль NN» = сравни `spec/NN-*.md` с кодом и реализуй ровно написанное, затем пройди раздел «Проверка».
- Любая правка кода обновляет соответствующий модуль в том же коммите: число в модуле = число в коде.
- После правок чисел: `npm run build`, `npm run balance` (без предупреждений), бот `__bot(<оружие>, 600, true)` без ошибок, затем коммит в `main`, пуш, `npm run deploy`, проверка живой страницы.
- Если текст модуля противоречит сам себе или другому модулю, скажи об этом, а не исправляй молча.
