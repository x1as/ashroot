# 18. Звук

**Суть.** Тихий синтезированный звук без файлов: щипковая лира в дорийском ладу для наград и интерфейса, глухие толчки и шорох воздуха для боя.

## Намерение

Прежний звук пользователь назвал невыносимым. Поэтому правила жёсткие: никаких пищащих тонов, никакого постоянного фонового гула, всё через компрессор, тише, чем кажется нужным.

## Правила

1. Звук только синтезом (Web Audio): струна Карплуса — Стронга (лира), шумовые всплески через фильтры, низкие «толчки» (синус с падением частоты).
2. Ноты лиры — дорийский лад; аккорды наград — восходящие 3 ноты.
3. Частые звуки (удар, блок, выстрел, магия, пепел, интерфейс) ограничены по частоте: не чаще раза в 40–120 мс.
4. Фонового дрона нет (функция оставлена пустой).
5. Звук выключается кнопкой «Звук» в паузе, выбор сохраняется. Аудио стартует после первого нажатия игрока (требование браузера).

## Связи

Вызывается всеми игровыми модулями. Кнопка звука — 16. Сохранение выбора — 19.

## Код

`src/engine/audio.js` (`pluck`, `thump`, `noise`, `sfx`, `setMuted`).

## Ручки

- Общая громкость и компрессор в `audio.js`.
- Лад: функция `note(n)`.

## Проверка

- 10 минут игры без раздражающих звуков; при массовом бою нет «каши» из одинаковых щелчков.

## Открыто

- Музыки нет.
