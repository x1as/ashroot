# 17. Графика и анимация

**Суть.** Чёткий пиксель-арт без размытия, плавное движение и сочные удары. Тёмный мир, яркое только то, что важно: телеграфы врагов, удары героя, редкость.

## Намерение

Пиксель-арт по правилам pixel-art-sprites: читаемый силуэт важнее деталей, жёсткие края, ограниченная палитра, только целочисленный масштаб. Плавность через субпиксельное положение камеры и анимацию на 60 кадрах, а не через размытие.

## Рендер

1. Мир рисуется в буфер с плотностью **2 пикселя на единицу мира**. На экран буфер выводится **целым множителем** `k = round(min(ширина, высота) × dpr / 500)` со сдвигом камеры на доли пикселя. Длинная сторона не больше 2560 px.
2. Все спрайты при запуске увеличиваются алгоритмом **Scale2x**: диагонали гладкие, но без размытия.
3. Сортировка по Y: герой, враги, пропсы, снаряды перекрывают друг друга по глубине.
4. Свет: слой в ¼ разрешения, каждая лампа — заранее нарисованный спрайт света; градиенты в кадре не создаются. Туман 0.2 (полный обзор комнаты).
5. Частиц не больше лимита, пуль не больше 220 (защита от просадок у Сердца Тифона).
6. Цель: средний кадр ≤ 1 мс на ноутбуке при 138 пулях.

## Спрайты

| Что | Как устроено |
|---|---|
| Герой | собирается из головы, торса и ног по весу надетой брони (без шлема / пилос / халкидский / коринфский и т. д.); 2 кадра дыхания (500 мс), 4 кадра бега (шаг ~100 мс при полной скорости); плащ-шарф на верлет-физике цветом героя |
| Оружие | спрайт на тип (модуль 05), металл по редкости: железо, бронза, сталь, золото; у Титанического фиолетовое, у Божественного золотое пульсирующее свечение. Аспис: круглый щит на второй руке |
| Враги, боссы | по спрайту на вид; при уроне белая вспышка; заморозка — голубой налёт, камень (Эгида) — серый; элита с цветной обводкой свойства |
| Иконки предметов | 16×16, общий контур, палитра редкости; рисуются ×4 или ×6 |
| Пропсы | амфора, сосуд с огнём, жаровня с искрами, статуя гоплита; при ударе покачиваются |

## Анимация ударов героя

1. Каждый удар: замах (оружие отводится, тело чуть приседает) → удар (оружие проходит дугу, тело вытягивается, 2–3 полупрозрачных следа оружия) → восстановление (плавный возврат).
2. Луч и конус: оружие отводится назад и выбрасывается прямо вперёд. Удар в точку: оружие поднимается высоко за спину и падает через прицел.
3. Рисунок удара повторяет его форму (модуль 04):
   - дуга — полумесяц из двух слоёв (цвет ауры + металл), у тесака ещё тёмная масса, у лабриса обратная дуга второго лезвия;
   - луч — сужающийся клинок света + белое ядро + кольцо на острие + искры;
   - конус — заливной клин; удар щитом — бронзовый клин и кольцо;
   - точка — короткий взмах, через 0.03 с вспышка-диск на земле, кольцо пыли, трещины, тряска;
   - крест — два скрещённых луча;
   - круг — полный оборот и кольцо.
4. На каждой цели — белый росчерк, искры, кровь цвета врага.

## Ауры богов

Доминирующий аспект (модуль 07) красит дуги, стрелы и снаряды посоха. С уровня 2 вокруг оружия цветное пульсирующее свечение. С острия летят частицы, частота растёт с уровнем:

| Бог | Частицы |
|---|---|
| Гидра | зелёные капли яда падают вниз |
| Прометей | оранжево-жёлтые угольки поднимаются |
| Борей | белые и голубые снежинки оседают |
| Зевс | короткие жёлто-белые искры во все стороны |
| Никта | фиолетово-чёрные струйки поднимаются |

## Обратная связь

Стоп-кадр, тряска экрана, толчок камеры в сторону удара, вспышка экрана (контр, идеальный перекат, полный заряд), замедление времени (идеальный перекат, резонанс, полный заряд, смерть). Враг погибает, рассыпаясь пикселями по направлению удара.

## Связи

Формы ударов — 04, 05. Ауры — 07. Цвета редкости — 08. HUD — 15.

## Код

`src/engine/sprite.js` (запекание, Scale2x, `RES`), `src/art/pixels.js` (сетки спрайтов), `src/art/bank.js` (сборка героя, оружие по редкости, свечение, `weaponTint`), `src/art/items.js` (иконки), `src/engine/fx.js` (частицы, дуги, лучи, конусы, диски, кольца, тексты), `src/game/scene.js` (рендер, свет, камера), `src/game/player.js` (`swingFx`, `drawWeapon`, `auraFx`).

## Ручки

- Длительность эффектов ударов (0.12–0.36 с).
- Частота частиц ауры.

## Проверка

- При увеличении скриншота края спрайтов резкие, без размытия.
- Махайры в двух руках, у асписа видно щит.
- Удар палицы сверху оставляет круг на земле перед героем.

## Открыто

- Анимации атак врагов простые (наклон и вспышка), отдельных кадров замаха нет.
